# Team profile images

Replace each supplied initials placeholder with the corresponding member's photo:

- Leader: `assets/team/leader/profile.png`
- Second member: `assets/team/member2/profile.png`

Keep the exact filename `profile.png` in each separate folder. A square image of
at least 480 × 480 pixels works well. The app fits it into the profile layout.
Refresh the app after replacing a file. No image upload to an external service
is required. If a photo is missing or invalid, the page shows a safe initials avatar.

Edit second-member details in `data/team.json`. Keep `id` values and image paths;
replace the `XXXXYYYY` placeholders in the other fields.
